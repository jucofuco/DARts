## Author credit on every page

Applies to every page of this project, because it is served from jucofuco.github.io (`projects/darts`).

Every such page, including new and secondary pages (privacy, terms, game pages, etc.), must carry the same credit in its footer, with the same wording and URL everywhere:

```html
<span class="footer-by">by <a href="https://jucofuco.github.io" target="_blank" rel="noopener">jucofuco</a></span>
```

- Small and muted, so it never competes with the page content. Keep it keyboard-focusable with a visible focus style.
- Do not reword it, translate it or point it anywhere else.
- When you create a page without it, add it before you finish.
